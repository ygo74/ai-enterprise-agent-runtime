# Documentation

Use the pages for your role:

- [User and operator guides](users/README.md): install, configure, run, and call
  the runtime.
- [Contributor guides](contributors/README.md): understand and change runtime
  domains.
- [Detailed Python library guides](python/README.md): package APIs, examples,
  and Python-specific behavior.
- [System specification](../spec/README.md): current contracts and behavior.
- [Runnable samples](../samples/README.md): complete integrations and
  small examples.

Issue-specific specifications and plans are tracked under
[`spec/implementation/`](../spec/implementation/README.md). Durable system
behavior belongs in the domain pages under `spec/`.
