# Samples

Runnable samples are grouped by implementation language. Start with the
catalog for the language you use:

- [Python samples](python/README.md)

Future language catalogs should use `samples/<language>/` and provide their own
README. Add a link here when a catalog is introduced. This keeps the top-level
index ready to grow without adding empty directories for languages that do not
yet have samples. Existing .NET and Java samples remain in
[`examples/`](examples/README.md) until their catalogs are moved in a separate
change.
