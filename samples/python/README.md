# Python samples

These runnable projects demonstrate Python integrations with the agent runtime.
Each project README describes its dependencies, configuration, and run steps.

## Catalog

- [FastAPI runtime quickstart](python-fastapi-quickstart/README.md): basic
  endpoints, typed outputs, JWT, and OIDC/Keycloak.
- [LangChain and FastAPI](python-langchain-fastapi/README.md): six framework
  integration scenarios from getting started through MCP configuration.
- [Microsoft Agent Framework and FastAPI](python-agentframework-fastapi/README.md):
  six MAF scenarios, with framework-specific behavior and limits documented.
- [MCP server](python-mcp-server/README.md): a protected streamable HTTP server.

New Python projects belong under `samples/python/`. A future language catalog
can follow the same `samples/<language>/` layout and be added to
[`samples/README.md`](../README.md) when it is ready.
