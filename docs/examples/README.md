# Examples

- dotnet-agentframework
- python-langchain-fastapi
- python-agentframework-fastapi
- java-springai-springboot

`python-langchain-fastapi/01-get-started` and `python-agentframework-fastapi/02-get-started-maf`
implement the same AI Solution Architect agent with two different agent technologies (LangChain vs
Microsoft Agent Framework), both exposed through the same `ygo74.agent_runtime` library, to demonstrate
that the library is agent-framework-agnostic.
